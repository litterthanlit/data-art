## Findings considered and rejected

- Extract dominant colours per cell instead of averages: not possible from the source. The API's
  `thumbnail.lqip` is a 4×5 or 8×5 pixel GIF, already an average, and the museum's image server
  returned HTTP 521 to build-time thumbnail requests. Deferred until a collection with openly
  served images is used.
- Keep additive blending and only add tone mapping: tested. Lit-pixel saturation reached 0.34 but
  the cloud turned dim and lost its structure. Opaque pigment was clearer in every state.
